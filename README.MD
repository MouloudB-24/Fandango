# 🎬 Fandango Movie Ratings Bias Analysis

Ce projet analyse les biais potentiels dans les évaluations des films sur Fandango en 2015, en comparant les notes de différentes plateformes.

## 📊 Données
Les données proviennent de l'article de FiveThirtyEight :  
[Fandango Movie Ratings](https://fivethirtyeight.com/features/fandango-movies-ratings/)
